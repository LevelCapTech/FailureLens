## 最終測定の約束

使うデータ: **Gate C v4(新しい最終評価データ。作成後、誰も結果を見ていないもの)**。Gate C v3 は使用済みで、使いません。使えるのは**1回だけ**です。実行にはオーナーの承認が要ります。

| # | 基準 | 内容 |
|---|------|------|
| F1 | 改善幅 | Top-1 が v5 より +0.05 以上、MRR が +0.03 以上で、MRR の差の95%区間(リポジトリ層別ブートストラップ、10,000回、乱数 20261030)の下限が 0 より大きい |
| F2 | 後退しない | どのリポジトリでも MRR が v5 より 0.05 を超えて悪くならない |
| F3 | 速さ・軽さ | 索引づけ込みの処理時間 p95 が 5 秒以下、メモリ 8 GiB 以下 |
| F4 | 本体と評価用の一致 | 本体の出力が、評価用の実装(凍結した定数)の順位と全ケースで一致する |
| 参考 | Gate B の絶対基準 | 関数 Top-1 ≥ 0.4 かつ MRR ≥ 0.6 を満たすか(満たさなくても F1〜F4 の判定は変えない。事実として書く) |

- F1〜F4 をすべて満たしたら「独立データでも v5 より良かった(合成データ、小さなライブラリ)」と書きます。標準にするかは、その結果を見てオーナーが決めます。
- 満たさなかったら、事実を書き、測り直し・重みの変更はしません。
- 評価データに「原因が必ず製品側のコードにある」前提があることを、レポートに必ず書きます。
- 集計値だけを出します。
