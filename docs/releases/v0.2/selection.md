# v0.2 候補モデルの選び方と結果

状態: **選定完了(2026-11-07)**。ルールは、候補の点数を見る前に書いてコミット済みです(コミット `5b3b7ed`)。

## 選定ルール(固定)

候補は最大5つ(a, b, c と、必要な場合の d, e)です。次の順で1つだけ選びます。

1. **足切り(失格条件)**
   - 学習が正常に終わっていること。
   - 損失が有限で、極端に壊れていないこと。
   - 過学習の疑い(MLflow の `overfit_signal`)が出ていないこと。
2. **選ぶ基準**
   - 開発用データ(dev)での関数レベルの MRR が最も高い候補を選びます。
   - 同点なら、validation 損失が低い候補を選びます。
3. **さらに必要な条件**
   - 選んだ候補は、dev データで現行 v0.1 モデルを上回っていることが必要です。
   - 上回らなければ、「v0.2 の候補は v0.1 より良くない」と報告します。
4. **最終評価(Gate C)について**
   - 最終評価データはこの選定に使いません。
   - 選んだ1候補だけを、後で1回だけ最終評価します。

| 候補 | 学習率 | epoch数 | 1回のバッチ | train損失(最終) | validation損失(最終) | 最良epoch | 過学習の警告 |

| a | 2e-5 | 8 | 8 | 0.251 | 0.446 | 8 | なし |
| b | 5e-5 | 8 | 8 | 0.101 | 0.367 | 8 | なし |
| c | 1e-5 | 12 | 16 | 0.328 | 0.465 | 12 | なし |
| (参考)v0.1 | 2e-5 | 3 | 2 | 0.516 | 0.720 | 3 | - |

- 損失は小さいほど良い数値です。3候補とも、最後のepochまでvalidation損失が下がり続けました。
- train損失とvalidation損失の差は、aが0.19、bが0.27、cが0.14でした。大きくは開いていません。
- v0.1より損失が小さいのは、学習データを12件から178件に増やしたためです。ただし、v0.1とは確認用データが違うため、損失どうしの直接比較は参考値です。
- 最初の実行(候補a)は、GPUメモリ不足で途中で止まりました。メモリ節約の設定(micro_batch_size)を追加して、同じ条件の計算で再実行しています。MLflowには失敗した実行も残っています。

### 開発用データ(dev)での点数

dev は4リポジトリ・62ケースで、学習にも最終評価にも使っていません。比べた相手は「語彙の一致で順位付けする方法」です(候補をあらかじめ与えた条件)。

|------|-----------|----------|--------------------------|------|
| 語彙baseline | 0.677 | 0.820 | - | 比較対象 |
| v0.1(現行) | 0.629 | 0.788 | -0.032 | 参考 |
| a | 0.629 | 0.804 | -0.016 | 不採用 |
| **b** | **0.710** | **0.844** | **+0.024** | **採用(次の最終評価へ)** |
| c | 0.613 | 0.788 | -0.032 | 不採用 |

### 採否の理由

- **b を選びました。** dev の MRR が最も高く(0.844)、過学習の警告もなく、現行 v0.1(0.788)を上回っています。ルールの条件をすべて満たしました。
- **a** は MRR 0.804 で、b より低い点数でした。
- **c** は学習率が小さく、epoch数を増やしても学習が進みきらず、MRR 0.788 でした。v0.1 と同じ点数です。
- **注意:** bの優位は小さく、統計的には「差がない」範囲です(MRRの差の95%区間は -0.078 から +0.126 で、0をまたぎます)。つまり、b が語彙baselineより良いとはまだ言えません。b が選ばれたのは、候補の中で相対的に最も良かったからです。
- この結果は dev での選択であり、最終評価(Gate C)の合否ではありません。

### 実施できなかったこと

- 実際の製品の検索結果を共通の候補にする比較(product pool)は、dev データでは実行できませんでした。評価コードが「同じ名前の関数が複数ある候補」を厳格に拒否するためです。dev の比較は、候補をあらかじめ与える方式だけです。
- 学習データの基礎的な再現性(同じ設定で複数回の学習)は、時間の都合で候補ごとに1回だけです。点数の差の一部は、ばらつきかもしれません。
