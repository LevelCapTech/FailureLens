# Examples

Runnable examples for FailureLens. All use only the core install (no ML
dependencies, no network).

| Path | What it shows |
|------|---------------|
| `python/diagnose_example.py` | Diagnose the sample failure via the Python API. |
| `cli/` | CLI usage recipes (text + JSON). |
| `agent-integration/` | How an AI coding agent can call FailureLens and parse JSON. |
| `fixtures/sample_project/` | A tiny project with a latent bug + captured `failure.log`. |

```bash
python examples/python/diagnose_example.py
```
